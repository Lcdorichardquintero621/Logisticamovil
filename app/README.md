# LogisticaMovil

App Android (Kotlin + Jetpack Compose) para buscar fotos, videos, música, documentos y archivos ocultos,
verlos en una lista (nombre, ubicación, formato, tamaño, fecha), abrirlos, moverlos, eliminarlos
(uno o varios a la vez) y detectar/eliminar duplicados conservando siempre una copia.

## Compilar el APK en GitHub
1. Sube todo este proyecto a un repositorio (incluida la carpeta `.github/workflows/build.yml`).
2. Ve a la pestaña **Actions** → **Build APK** → **Run workflow** (o simplemente haz push).
3. Al terminar, abre la ejecución y descarga **LogisticaMovil-APK** (contiene `app-debug.apk`).
4. Cópialo al teléfono, instálalo y concede el permiso de "Acceso a todos los archivos".
